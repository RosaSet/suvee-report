# SUVÉE Report — Digital Marketing & Video Operations Portal

A modern operations and reporting web platform for Facebook Page Boosts, TikTok Ads, and Creative Video Production.

## Features
- **Daily Performance Reports:** Facebook Page Boosts & TikTok Ads tracking.
- **Video Editor SOP & Hooks:** Video creatives, formats, and hook tracking.
- **Weekly Content Management:** Content calendar by Week 1-4 with script attachments.
- **Boss & Staff Management:** Role-based access and permissions.
- **Database:** Supabase Cloud Database with auto-sync and offline localStorage fallback.

## Tech Stack
- React 19 + Vite
- Supabase Cloud Database (PostgreSQL)
- Lucide React Icons
- Vanilla CSS Glassmorphism Design System
